============================================================
                    REGRAS CRÍTICAS
============================================================

1. NUNCA MEXER NO SITE DE AGENDAMENTO NESTE CHAT
   - O site de agendamento tem seu próprio chat exclusivo
   - Qualquer alteração no agendamento deve ser feita
     no chat dedicado ao projeto
   - O sistema está funcionando perfeitamente há 2 meses

2. OS PROJETOS SÃO INDEPENDENTES
   - Alterações no website NÃO devem afetar o agendamento
   - O subdomínio agendamento.korehaus.com.br é separado
   - Ambos estão no Vercel mas são projetos distintos

3. CONFIGURAÇÃO DNS (Hostinger)
   - korehaus.com.br (A record) -> 76.76.21.21 (Website)
   - agendamento.korehaus.com.br (A record) -> 76.76.21.21
   - Os dois apontam para Vercel mas para projetos diferentes

4. EM CASO DE DÚVIDA
   - NÃO execute comandos que possam afetar korehaus-agendamento
   - Sempre verifique qual projeto está sendo alterado
   - Na dúvida, pergunte antes de executar
